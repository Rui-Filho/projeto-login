# Projeto Login

Projeto de estudo desenvolvido durante o aprendizado de **HTML5 e CSS3**.

Uma tela de login responsiva, criada para praticar a construção de formulários, **Mobile First** e **Media Queries**.

## Tecnologias

- HTML5
- CSS3
- Google Material Symbols

## Objetivo

Praticar conceitos de estruturação de páginas, formulários e desenvolvimento de layouts responsivos.
